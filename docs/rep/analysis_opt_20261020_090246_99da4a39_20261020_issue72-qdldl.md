**Verdict: rejected on measurement.** Seven of the eight decision items hold. The one that fails is the one that
asks whether qdldl's answers are as good: scored on the same QPs, its posteriors sum to Σ_t J **3,128,188.8**
against faer's **3,126,851.3** (+1,337.5, **+0.043 % vs `opt_20261019_171746_3272682b`**), lower in only 13 of

first-year feasibility probe takes 444 s in both runs. `DIRECT_SOLVE_METHOD` stays `"faer"`.

## 1. Change

Clarabel factorises each interior-point iteration's KKT system with a sparse LDLᵀ. #70 pinned that linear solver
(faer, Clarabel's automatic choice on copper) to one thread per period. qdldl is Clarabel's other built-in
LDLᵀ, single-threaded. The scratch benchmark behind #72 found it ≈ 5× faster per period on
`const_20261012_113828_12c562c7`, with objectives moving by −122 … +311 per period in both directions. That
constraint run has since been pruned, so the measurement moved to the final chain, whose own faer solve is the
base. The probe (`feasibility_check`) keeps Clarabel's default settings in both runs.

## 2. Decision rule (fixed before the run) and result

Both solves stop at Clarabel's numerical floor (ADR 0039), not at the exact optimum, so a different linear solver
lands on a different point near it. The rule therefore scores both posteriors on the same objective,
J = Σ((F − a₀)/σ_a)² + Σ_free ((G F − c)/σ_c)², recomputed from `F_opt` in the solver's conditioning (the
`roundZ_png_kg_diag._J` cross-evaluation), and adopts qdldl only if it is not worse anywhere it matters.

The cross-evaluated ΔJ equals the per-period Δ of Clarabel's own objectives to the reported digit: both runs

(1,158,162.4 → 1,159,389.5, +0.106 % vs base) and the prior term the rest. The common-set sum-row z² rises
+0.106 % vs base (1,149,839 → 1,151,053 on 27,458 rows); the largest regional rises are China +584 and
Chile +380. Mass moved on CC edges rises 399,370 → 402,457 kt (+0.77 % vs base).

## 5. Reading

- **qdldl is faster, not better.** It takes as many iterations as faer (Σ 6,915 against 6,969) and each costs
  about a fifth of the time. Where it stops near the floor is a different point, slightly worse on balance. The
  per-year moves (−150 … +560 J) are of the size ADR 0039 already accepts as the floor's distance from the
  optimum, so neither solver's answer is wrong. But nothing here makes qdldl's answer preferable, and adopting it
  would move every number of the manuscript chain for 3 min of wall-clock.
- **The probe is the remaining lever.** At 444 of 563 s it is 79 % of Stage 4 under qdldl and 60 % under faer.
  #55's per-period probe through the thread pool is where the next minutes are.
