## 1. Change

- **stock_bounds v5 → v6.** `scripts/explo/stock_bounds_study.py` is re-run on icsg v15 (root labels). The pooled
  p95 of |PSC| / refined-cathode output falls 0.0489 → **0.0276**: n 499, median 0, p99 0.0834. All 47 rows
  change only `value_min`, `value_max`, the bounds and the description.
- **Why the band falls.** v5 was built on icsg v12. #65 then repaired the stock parse (net additions differenced
  within one vintage), and ICSG's PSC series shrank from Σ|PSC| 9,135 kt (v12) to 2,995 kt (v13–v15).
- **The study's guard.** `PSC_P95_WINDOW` was (0.03, 0.08). Its job is to catch the denominator collapse that once
  inflated p95 ~70×. Its lower bound refused the repaired band, so it moves to 0.01.
- **The 0.1 kt scale floor stays.** It is measured latent:
  - on the base, the 428 rows with σ_c < 0.01 kt hold Σz² 3.80, max |z| 0.771;
  - no region-year with CP→Cathode prior < 1 kt carries a nonzero PSC prior (0 in both runs).
  The near-pins hold PSC at zero exactly where there is no refinery output: "no producer, no producer stock."
- **What v6 reaches.** Stage 2's ShareImputer reads the same p95 but writes no CP→PSC edge on this chain. ICSG
  (223 edges), the NetworkImputer (854 forward, 1,077 mass twin), the flat prior (660) and time interpolation (6)
  set them all before step 11. In Stage 3, σ_r = 0.0276/1.645 = 0.0168 falls below `RATIO_SIGMA_REL_FLOOR` 0.02, so
  the rows tighten 0.0297 → 0.02, a factor of 0.673.
