# Grade-basis fix — region×year in-situ ore grades replace the global 1 % placeholder

**Implements:** [ADR 0015](../adr/0015-in-situ-ore-grades-on-allocated-ore-basis.md).
**Chain:** `ore_grade v2` (scripts/build_ore_grade.py, NEW) + `conc v5` (CO/Ore rows retired) →
`imp_20260903_083103_4a7e63fd` → `const_20260903_083616_8167e3a8` →
**`opt_20260903_084528_45fdd041`** (cold, 30/30 Solved, same feed runs as the mapped-self-trade run).
**Branch:** `sensitivity/no-flat-prior-zeros` · **Date:** 2026-09-03 · Suite 872 passed / 1 skipped.

## The problem (specified in the plan; short form)

Three grade quantities per region-year on two bases, none of the real data in the QP: crude_ore
Mass is S&P **price-allocated** ore; the S&P grade (1/factor) is **recovered**-basis; the CO/Ore CC
priors are **in-situ** (production ÷ eff, network-backward). The QP's only grade coupling was the
conc family's **global 1.0 % nominal with a global [0.3, 1.7] % hard band** — Chile's posterior
grade drifted to 1.70 % against the accidental cap, Australia's allocated grade (1.81 %+) exceeded
the cap from day one, and the S&P region×year grades were unused (imputer-twin fallback only).

## The fix

`scripts/build_ore_grade.py` (mirrors build_trade_shares) reads the registered icsg + crude_ore
feed runs' F_root and writes region×year **in-situ** grade rows
(`g = [Conc/0.8 + SXEW/0.725]/OreMass`; eff nominals from the eff params; S&P-factor fallback ÷0.8;
per-region band = series min/max ∓/± 10 %) — 830 region-years × 3 conc-family roles = 2,490 rows.
The conc family's global CO/Ore rows are retired (generator skip + live-file removal). Registered
with both Ratio builders; the imputer twin map picks the rows up via the existing `conc_twin_map`
overlay (region-resolved rows win on specificity — no imputer change, verified by test).

## Reading the numbers

- **The grade layer is now honest.** Priors are internally consistent by construction; posterior
  grades are anchored per region (soft |z| max 17.8, no hard violations); Australia's
  allocated-basis grades stopped fighting a cap never meant for them; global soft strain fell
  again (p99 20.9 → 14.7 → 12.65 across the three rounds).
- **Chile recovered only +5 pp (0.37→0.42) — the measured verdict the round was designed for.**
  The grade tension is gone, but Chile's posterior still runs to its band ceiling because the
  residual force is the **Mass-vs-CC data tension** (trade-Mass/BACI chain vs ICSG-CC chain) plus
  the **cv-proportional σ economics** (Chile→China/Japan concentrate legs still zeroed — deleting
  the biggest legs remains the cheapest reconciliation). That σ-design question is now cleanly
  isolated as the next lever.
- **The next inconsistency family surfaced** (expected when a layer stops absorbing strain):
  `conctailingsuse` z-tails (Panama −84, US −69, Mexico −64 in 2022) — the Tailings Mass residual
  (Ore−Concentrate) vs Tailings CC ((1−eff)·in-situ) implies tailings grades outside the global
  conc band; same class as the CO/Ore fix, one level down.

## Follow-ups

1. **Export-leg σ design** (the isolated Chile lever): cv-proportional σ makes big bilateral legs
   the cheapest tonnes to delete; consider an absolute σ component or leg-count-aware weighting.
2. **Tailings conc rows** — regionalise on the allocated basis (same recipe as this fix).
3. **Germany fabricated Ore chain** (z −58.6, unchanged — no ore mass ⇒ no grade rows); trace the
   `Ore→MF` 5,744 kt prior's origin.
4. EU-refiner CP holes (8 regions), PSC z-tail, pre-check fragility — standing.
5. 35 region-years with ore mass but no grade source (all tiny; logged by the generator).
