## 1. Change

`ore_grade` is derived (ADR 0015): ICSG mine production ÷ allocated ore mass, region × year. v7 (2026-09-16) was
built before icsg v10–v15. Those versions removed the 2014 yearbook's misattributed Mining/Total rows (ADR 0035),
split Scandinavia (#73, #74) and relabelled the 2005 yearbook's Congo (#85). v8 rebuilds it on icsg v15's feed run.
