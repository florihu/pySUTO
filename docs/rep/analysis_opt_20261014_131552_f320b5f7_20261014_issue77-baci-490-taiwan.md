## 1. Change

#77 maps BACI code 490 ("Other Asia, nes", Taiwan's trade in UN Comtrade and BACI) to Taiwan instead of ROW.
- **Before:** Taiwan was trade-blind, and its ICSG fans stayed undistributed (ADR 0018). ROW's imports carried
  Taiwan's cathode, which gave ROW's domestic semis share a zero weight (#76).
- **The guard.** The netting maps codes through its source version's region map, and #77's guard refuses a
  source whose map differs from `current/`'s. So this chain starts at the BACI re-parse.
- **What the re-parse changes.** The re-parse is code-level. It reproduces v13's `values.csv` and
  `quantity_recon.csv` exactly. Only the ADR 0033 σ sidecar changes: 56 root-leg keys, every one touching ROW
  or Taiwan, with the same total mass.

- **Semis use.** The base books 3 kt CC against ICSG's 15,460, with a prior of 0. The new run gives prior

## 5. ROW: the contradiction now runs the other way

Section N reads ROW's cathode rows in the re-export ledger. ROW is excluded from the netting (`HUB_EXCLUDE`),
so these are its unnetted totals. The quantity is ICSG's ROW cathode use U (semis, USC, MESC) minus ROW's
cathode balance, ICSG production P plus BACI imports I less BACI exports X. U − (P + I − X), kt CC:

| ledger | 1995–2011 | 2012–2024 |
|---|---|---|
| baci v18 (base; 490 in ROW) | −6,886 (−243 … −610 a year until 2012) | +353 |
| baci v20 (new; 490 → Taiwan) | **+2,355** (+16 … +261 a year) | **+5,829** (+161 … +752 a year) |

- **Base.** ROW's apparent consumption exceeded ICSG's use by 243–610 kt CC a year through 2012. That is the
  surplus #75 found refilled onto ROW's domestic semis leg (#76).
- **New.** Taiwan's 375–655 kt CC a year of cathode imports (TODO, baci v18) leave ROW. ICSG now reports ROW
  using more than its production plus imports, less exports, in every year.

The solver settles this on ROW's domestic semis leg. Section R gives it as fed / posterior / production prior
− export prior, kt CC:

- **The leg settles at what ROW can supply.** The posterior follows ROW's own production less exports in

- **ROW's refined cathode survives.** `CP→Cathode` posterior/prior is 0.95–1.08 in 1995–2011 (base 0.93–1.06).

## 10. Consequences

1. **#82, the fix ticket.** ICSG's ROW cathode use exceeds ROW's production plus BACI imports, less exports,
   by 16–752 kt CC a year once Taiwan's imports leave ROW. A country-by-country comparison of ICSG's ROW members
   against BACI's imports into the same countries decides which input is wrong. Until then, the old chain's
   apparent fit rested on Taiwan's imports cancelling this gap.
2. **Merging is the maintainer's call.** Merging `fix/baci-490-taiwan` and this branch would make
   `opt_20261014_131552_f320b5f7` the reference chain.
   - **For:** Taiwan's 15.5 Mt CC of usage enters the account, and ROW's refinery output is no longer hidden
     by another region's imports.
   - **Against:** z² rises 1.41 %, because the remaining ROW gap is now visible rather than cancelled.
3. **#78 (#76's observed zero)** was sequenced after this run. On this chain ROW's domestic semis leg is fed
   and positive, so #78 measures the other regions in #76's class.
4. **#71.** This run is the milestone's first production run on the parallel solve; its comparison is
   posted on #71.
